# Use

This guide is for people who are new to the Voss HPK wiki.

## Find your way around

- Open a group in the sidebar to see the pages it contains.
- Use search when you are looking for a word, place or document.
- Use the locale selector at the top to switch between Nynorsk and English.
- Choose **Browse** if you prefer to navigate through the folder structure.

## Read a page

Click a link in the sidebar or in the text to open a page.
Use the page headings to find the section you need.
Some pages link to forms, maps or other documents.

## Edit and contribute

You can edit a page if your groups give you write access.
Choose **Edit** to open the editor.
Use the toolbar to add headings, lists and links.
Preview the page if that option is available, then save when you are ready.
Open the page in its normal view to check that the change looks right.
Page history shows earlier versions and lets you compare changes.
Contributors can create and edit pages, but cannot move or delete them.
Ask an editor for help if a page needs to be moved or deleted.
Keep the Nynorsk and English content in step when a page exists in both languages.

## Create a page in a folder

Enter the full page path when creating a page, for example `new-folder/new-page`.
When Nynorsk is selected as the language, leave `nn/` out of the path.
Wiki.js creates the folder path automatically when the page is saved.
The folder appears in GitHub when it contains at least one page and synchronization has run.
New top-level folders mapped to a navigation group appear there by default.
New top-level folders and root-level pages without a mapping appear under the expandable **Ungrouped** menu item.
Pages in nested folders appear under the menu link for their containing folder.
If the folder has no landing page, its pages appear as direct links under **Ungrouped** with the folder name first.
This grouping is only for the sidebar; the page stays at the path you chose.

## Sidebar groups

Editors can create, rename, move and reorder groups and links in Wiki.js.
The navigation job keeps the group structure and placement of links that already exist.
To make a new top-level folder appear in a particular group automatically, its path must be added to the technical group list.
Create the group in Wiki.js first, then tell the wiki maintainer its exact label and the folder path.
If the group is not in the sidebar, new links go under **Ungrouped**.
Changing the technical group list does not move links that are already in the sidebar; move those links in Wiki.js if their placement should change.

## Who can do what?

| Group | What you can do |
| --- | --- |
| Guests | Can read pages only. |
| Contributors | Can read, create and edit pages, upload files and submit feedback. |
| Editors | Can edit, review, move and delete pages, and manage navigation. |
| Administrators | Manage Wiki.js settings, users, groups and operations. |

Contributors cannot review submissions, move or delete pages, or manage navigation.
Your access depends on the groups you belong to, and some pages may have their own access rules.
Ask an editor if you are unsure what you can do.
