# Course Framework

*Source: “Rammer for kursing i regi av Voss Hang- og Paragliderklubb”, dated 20 November 2023.*

## Minimum course staffing

| Students | Instructors | Assistant instructors/helpers | Note |
|---:|---:|---|---|
| 1 | 1 | — | An assistant instructor is required for the first five high flights. |
| 2–8 | 2 | — | |
| 8–11 | 2 | 1 assistant instructor + 1 helper | |
| 11–14 | 2 | 1 assistant instructor + 1 helper | |
| 14 or more | — | — | Split into two courses. |

> If a course does not have enough instructors to meet the minimum staffing level, the club must assess whether it can go ahead before the course.

## Training and experience requirements for instructors

| Requirement/activity | Instructor requirement | Note |
|---|---|---|
| Current VHPK course model | Attend one beginner course | |
| Min idrett / E-course / IKU | Internal training | |
| HPS instructor seminar | Attend within the last four years | |
| VHPK instructor meeting | Attend during the last year | |
| Flight logging | Log own flights | Flightlog or another log. |

## Training and experience requirements for assistant instructors

| Requirement/activity | Assistant instructor requirement | Note |
|---|---|---|
| New course model | Attend one beginner course | As a helper. |
| Min idrett / E-course / IKU | Internal training | |
| Assistant instructor course | Completed | |
| Instructor meeting | Attend during the last year | |
| Flight logging | Log own flights | Flightlog or another log. |
