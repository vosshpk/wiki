## Tema som treng eigne, oppdaterte rutinar

Desse punkta er tekne med frå rettleiaren for klubbhandbøker fordi dei er relevante for Voss HPK. Dei er ikkje ferdig avklarte her. Styret bør peike ut ansvarleg og vedta eller lenkje til gjeldande dokument.

| Tema | Status / neste steg |
|---|---|
| Treningsavgifter, kursprisar og deltakaravgifter | **MÅ AVKLARAST:** medlemskapssida viser til oppdaterte prisar, men ei samla forklaring av avgiftstypar, vedtak og refusjon manglar. |
| Aktivitetsplan, arrangement og reiser | **MÅ AVKLARAST:** lag kalender og rutinar for påmelding, reiseleiar, transport og ansvar under klubbturar. |
| Barn, ungdom og føresette | **MÅ AVKLARAST:** stadfest om klubben har aktivitet for mindreårige, og publiser relevante tryggleiks- og føresetterutinar. |
| Økonomirutinar, rekneskap og to signaturar | **MÅ AVKLARAST:** legg inn gjeldande rutine og ansvar i samsvar med vedtekter og årsmøtevedtak. |
| Forsikringar | **MÅ AVKLARAST:** dokumenter kva klubben, medlemer, tilsette og utstyr er forsikra gjennom. |
| Politiattest og trygg idrett | **MÅ AVKLARAST:** namngje ansvarleg rolle og lenk til gjeldande NIF-prosedyre. |
| Antidoping | **MÅ AVKLARAST:** dokumenter klubben si haldning og eventuell deltaking i «Rein idrettslag». |
| Dugnad og frivillig arbeid | **MÅ AVKLARAST:** forklar korleis oppgåver blir melde ut og fordelte, og kven som koordinerer. |
| Roller for pilotar, instruktørar og frivillige | **DELVIS DEKT:** progresjon og tryggleik er omtala; lag rolle- og forventningsavklaringar der dei manglar. |
| Kommunikasjon og personvern | **MÅ AVKLARAST:** fastset offisielle kanalar og rutinar for personopplysningar og bilete. |
| Arbeidsgjevaransvar og personalrutinar | **MÅ AVKLARAST:** avklar delegering, arbeidsavtalar og HMS for tilsette. |
| Anlegg, utstyr og forsvarleg bruk | **DELVIS DEKT:** sjå fasilitetar, klubbutstyr og flystadene; legg til vedlikehalds- og utlånsrutinar. |
| Utmerkingar og æresmedlemskap | **MÅ AVKLARAST:** stadfest om klubben har vedtekne ordningar. |
| Årshjul og oppfølging av mål | **MÅ AVKLARAST:** lag eit gjeldande årshjul; programplanen for 2025 er historisk. |

## Vedtak og revisjon

Styret bør vedta handboka og peike ut ein redaktør. Før publisering må utkast og placeholderar kontrollerast mot gjeldande vedtekter, årsmøtevedtak, NIF/NLF-reglar og faktiske rutinar. Første vedtak: **ikkje registrert**. Sist fagleg gjennomgått: **ikkje registrert**.
