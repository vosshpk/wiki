# Utmerkingar og æresmedlemskap

> **MÅ AVKLARAST:** Stadfest om Voss HPK har vedtekne utmerkingar eller æresmedlemskap. Dersom ordningar finst, dokumenter kriterium, kven som kan nominere, vedtaksorgan og korleis tildelingar blir kunngjorde.

Kontroller vedtekter og tidlegare årsmøtevedtak før nye ordningar blir oppretta.
