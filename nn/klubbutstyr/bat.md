# Redningsbåtane

Klubben har tre redningsbåtar:

- **Oransje jolle:** Yamaha 9,9 hk.
  Motoren er ny i 2026, og jolla står på eigen tilhengar.
- **Grå jolle:** Yamaha 25 hk.
  Jolla står på eigen tilhengar.
- **Raud Pioner Multi:** Yamaha 60 hk.
  Båten og motoren er nye i 2026, og båten står på eigen tilhengar.

Den grå jolla står vanlegvis på tilhengaren og er klar for oppdrag i Aurland eller under Veko.
Den oransje jolla og Pioner Multi ligg på Vangsvatnet og er i beredskap.

Den oransje jolla og Pioner Multi står alltid ulåste, slik at dei er tilgjengelege ved naud.
Start alltid motoren i fri og fest dødmannssnora før bruk.
Følg [naudprosedyrane](/tryggleik/naudprosedyrar), og meld frå til dagleg leiar om feil, skade eller behov for vedlikehald.

## Fortøying

Fortøyingsløysinga på Vangsvatnet er knutefri.
Hekt karabinkroken av og dreg båten inn til land.
Når du fortøyjer på nytt, dreg du båten ut til fortøyingsplassen og festar karabinkroken att.

## Sjekkliste for redningsbåt

### 1. Før sjøsetjing / klargjering av båten

#### Motor og system

- [ ] Kontroller drivstoffnivået.
- [ ] Opne lufteskruen på drivstofftanken.
- [ ] Kontroller propellen.
- [ ] Test at elektrisk tilt/trim fungerer.
- [ ] Kontroller at dødmannssnora er på plass.
- [ ] Slå på hovudstraumbrytaren.
- [ ] Start motoren og kontroller at kjølevatnet kjem ut.
- [ ] Kontroller at VHF-radioen fungerer.
- [ ] Kontroller at baugrampa fungerer (Pioner Multi).

#### Tryggleiks- og redningsutstyr

- [ ] Kontroller at det er nok redningsvestar/flyteplagg om bord.
- [ ] Kontroller at årer/padleåre er om bord.
- [ ] Sikre båra/redningsbrettet om bord.
- [ ] Kontroller at krokniven er om bord.

### 2. Redningsoppdrag

- [ ] Løysne låsehengslene på baugrampa før du senkar rampa (Pioner Multi).
- [ ] Nærm deg personen roleg og trygt.
- [ ] Hald propellen unna personar i vatnet.
- [ ] Sørg for at eitt av mannskapet held augekontakt med personen heile tida.
- [ ] Få personen om bord og sikre vedkomande.
- [ ] Hev baugrampa etter opptaket.
      Låsehengslene treng ikkje festast då (Pioner Multi).

### 3. Etter bruk

- [ ] Hev motoren med elektrisk tilt.
- [ ] Kontroller propellen for skadar.
- [ ] Fyll drivstoff.

### 4. Ved lengre lagring

Når båten ikkje skal brukast på ei stund:

- [ ] Slå av hovudstraumbrytaren.
- [ ] Steng lufteskruen på drivstofftanken.
