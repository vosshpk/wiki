# Klubbåten

Den oransje redningsbåten ligg på Vangsvatnet og er tilgjengeleg ved naud eller behov for assistanse.

- Båten er ulåst for naudbruk.
- Start motoren i fri og fest alltid dødmannssnora før bruk.
- Følg tryggleiks- og bruksrutinane i [naudprosedyrane](/tryggleik/nodprosedyrer).
- Meld frå til dagleg leiar om feil, skade eller behov for vedlikehald.
