# Rammer for kursing

*Kjelde: «Rammer for kursing i regi av Voss Hang- og Paragliderklubb», datert 20.11.2023.*

## Minste bemanning på kurs

| Tal elevar | Instruktørar | Hjelpeinstruktørar/hjelparar | Merknad |
|---:|---:|---|---|
| 1 | 1 | — | Hjelpeinstruktør er kravd på dei fem første høgdeturane. |
| 2–8 | 2 | — | |
| 8–11 | 2 | 1 hjelpeinstruktør + 1 hjelpar | |
| 11–14 | 2 | 1 hjelpeinstruktør + 1 hjelpar | |
| 14 eller fleire | — | — | Delast opp i to kurs. |

> Dersom kurset ikkje har nok instruktørar til å oppfylle minste bemanning, skal klubben vurdere gjennomføringa før kurset.

## Opplæring og erfaringskrav for instruktørar

| Krav/aktivitet | Erfaringskrav for instruktør | Merknad |
|---|---|---|
| Gjeldande kursmodell i VHPK | Delta på eitt grunnkurs | |
| Min idrett / E-kurs / IKU | Internopplæring | |
| Instruktørseminar HPS | Deltaking i løpet av dei siste fire åra | |
| Instruktørmøte VHPK | Deltaking siste år | |
| Loggføring | Eigen flyging skal vere loggført | Flightlog eller annan logg. |

## Opplæring og erfaringskrav for hjelpeinstruktørar

| Krav/aktivitet | Erfaringskrav for hjelpeinstruktør | Merknad |
|---|---|---|
| Ny kursmodell | Delta på eitt grunnkurs | Som hjelpar. |
| Min idrett / E-kurs / IKU | Internopplæring | |
| Hjelpeinstruktørkurs | Gjennomført | |
| Instruktørmøte | Deltaking siste år | |
| Loggføring | Eigen flyging skal vere loggført | Flightlog eller annan logg. |

## Vil du bidra på kurs?

Send e-post til [sikkerheit@vosshpk.no](mailto:sikkerheit@vosshpk.no).
Skriv litt om erfaringa di, kva som motiverer deg til å bli instruktør, og eventuelt kvifor du ønskjer å halde kurs i regi av klubben dersom du alt er instruktør.

For praktisk informasjon om utbetaling, utlegg og utstyr, sjå [rettleiinga for instruktørar på vosshpk.no](https://vosshpk.no/kurs/for-instruktorar/#elementor-toc__heading-anchor-0).
